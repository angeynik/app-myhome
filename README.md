# Клиент умного дома (Vue 3)

Веб-приложение для управления домом: показания датчиков, уставки, состояние устройств, видеонаблюдение.
Работает с сервером `server-myhome` по WebSocket. Код приложения — в [vue-app/](vue-app/),
правила разработки — [vue-app/claud_rules.md](vue-app/claud_rules.md).

```bash
cd vue-app
pnpm install
pnpm serve      # разработка с горячей перезагрузкой
pnpm build      # сборка в dist/ (публикуется по пути /app/)
pnpm lint
pnpm test
```

## История

### version_0_0_3_1 — 18.11.26

**Видеонаблюдение**
- Новая вкладка «Видеонаблюдение»: сетка до 16 камер, по нажатию — камера на весь экран.
- Кадры приходят только для карточек, видимых на экране; при уходе с вкладки — не приходят.
- Карточка «Нет сигнала», если кадр устарел; время кадра по Москве.
- После переподключения к серверу подписка на камеры восстанавливается сама.
- Список камер обновляется без перезагрузки страницы, когда на сервере меняется `cameras.json`.

**Связь с сервером**
- Сессия восстанавливается после каждого подключения, в том числе если сервер был недоступен при загрузке.
- Ответы сервера об окончании сессии: сначала попытка восстановить, выход — только при отказе.
- Изменения из других вкладок и от устройств приходят для всех разделов (`system` и др.).
- Ошибки сервера (например, отказ записи в устройство Modbus) показываются пользователю,
  затронутые данные перезапрашиваются.
- Исправлена двойная отправка значения на сервер.

**Приложение (PWA)**
- `manifest.json` и иконки работают при публикации по пути `/app/` (раньше — ошибка 404).

**Зависимости и инструменты**
- Vue 3.5, Vue Router 4.6, Vuex 4.1, Vue CLI 5.0.9, ESLint 8; удалены неиспользуемые пакеты
  (`@vueuse/core`, `socket.io-client`, `vue-touch`, `vuejs3-logger`, `vue-svg-loader`, `vue2-touch-events`).
- ESLint знает о среде Jest — `pnpm lint` проходит без ошибок.
- CI (GitHub Actions) на pnpm и Node 20: установка, lint, тесты, сборка.

**Тесты**
- Новые тесты: восстановление сессии, отправка значений, видеонаблюдение (модуль и вкладка).
- 298 тестов: 253 проходят, 45 — известные устаревшие тесты, ещё не обновлённые под текущий код
  (в CI не блокируют сборку).
